Détourage IA

Retirez le fond d'une photo

L'IA garde la personne ou le véhicule et efface le reste. Remplacez ensuite le fond par une couleur ou une autre photo. Pratique pour créer vos personnages et vos visuels.

Choisissez une photo. Le premier usage télécharge le modèle d'IA.

Résultat

Modèles : MODNet (Apache 2.0) pour les personnes, ORMBG (Apache 2.0) pour les objets, via transformers.js.
